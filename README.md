# 一亿条淘宝用户行为数据分析看板
## 对一亿条数据进行数据分析，用于平台运营与改进
### 1.看板链接：  
[分析看板](https://taobao-user-behavior-analysis-kncwvd2k3x7sappqykhb6n.streamlit.app/)  
### 2.数据来源：  
[阿里云天池 UserBehavior 数据集](https://tianchi.aliyun.com/dataset/649)  
规模约一亿行，3.5GB。该数据是公开数据，任何人可下载核验。  
### 3.分析流程：  
原始数据 → MySQL 入库（LOAD DATA）→ 清洗（对账）→ 建索引/中间表 → 18 张聚合表导出 → pyecharts画图→Streamlit可视化  
### 4.技术亮点：  
一： 通过LOAD DATA 原生批量快速导入一亿条数据。  
二： 通过按天分组排查一亿行、发现 2017-11-24 一天就占脏数据的72%（40,231/55,576）、按年分组挖出负时间戳和 36 个异常年份。最后通过where过滤掉55,576条脏数据。  
三： 在建立中间表item_t时忽略了索引，是因为item_t 的过滤条件命中约 99.95% 的行，选择性极低，此时走索引（大量回表）反而不如全表扫描（顺序 IO）；
实测对比后，用ignore index 强制全扫。  
四： 建立三张中间表，将包含大量数据查询的一次运行结果作为缓存表，用于后续查询，大幅度加速查询速度：其中就有曝光前十商品查询从 19 分 37 秒 → 11.1 秒（快约107倍）  
### 5.数据核验对账：  
数据清洗掉55,576条脏数据，经查询，清洗后的数据量为100,095,231，两者之和刚好为总数据量100,150,807，说明清洗没有丢数据、没有多数据；
以及中间表item_t四列计数总和 = 100,095,231，说明中间表的建立没有丢一行数据
### 6.本地运行：  
pip install -r requirements.txt + streamlit run app.py
